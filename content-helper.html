Local Helper / 本地辅助工具

Aiko Works 内容添加助手

这个页面是“新作品填写说明 / 添加作品辅助页面”。它只在本地辅助生成代码片段，不会保存文件，也不会上传内容。把素材放进 assets/ 后，填写下面的表单，复制生成的对象，粘贴到对应的 data/*.js 数组里即可。

如何添加新作品

先把图片、音频、文章或 PDF 放进 assets/ 对应文件夹，再填写下面的 Work 表单。点击“生成作品对象”后，把生成的代码追加到 data/works.js 的 works 数组里。

  • summary 是列表页摘要，让读者点开前快速知道作品内容。
  • content 是详情页正文，可以放完整诗歌、散文或创作说明；没有正文时留空。
  • cover 留空会使用分类默认封面，images 用来放真正的作品图片。
  • 新增作品后，“日记 / 更新记录”会自动从 data/works.js 生成新增记录。

修改已有内容

用于修改已经添加到作品集里的文章、绘画、音乐或其他作品信息。这个模块不会直接编辑 works.js，而是帮助你找到要改的作品，并生成可以复制给 Codex 的修改说明。

修改步骤

  1. 打开 data/works.js。
  2. 用作品标题、id 或日期搜索对应作品。
  3. 找到后，只修改该作品对象里的字段。
  4. 不要新建重复作品，也不要误删其他作品。
  5. 保存后刷新 index.html，检查作品列表、详情页和更新记录。

可修改字段说明

id：作品唯一编号，一般不要改，避免影响详情按钮、更新记录和相关引用。
category：作品分类，只使用 painting、writing、music、game、craft。
date：作品日期，会影响作品显示和更新记录排序。
zh.title：中文标题。当前项目不使用顶层 title 字段。
ja.title：日文标题。当前项目不使用顶层 titleJa 字段。
zh.summary：中文摘要，显示在作品列表页。
ja.summary：日文摘要，显示在日文作品列表页。
zh.content：中文正文，显示在详情页；多行诗歌、散文请用反引号。
ja.content：日文正文，显示在日文详情页。
zh.commentary / ja.commentary：作品说明，可选，会和正文分开显示。
tags：标签数组，例如 ["诗", "梦"]，每个标签都要加引号。
cover：封面路径，留空 "" 则使用分类默认封面。
images：图片文件路径数组，用于真正的作品图片；当前项目不使用顶层 image 字段。
files：文章、PDF、音频或外部链接数组；音乐请使用 { type: "audio", url: "assets/audio/example.mp3" }，当前项目不使用顶层 audio 字段。
featured：是否精选，使用 true 或 false。

修改字段模板

// 修改已有作品时，请先搜索 id 或 zh.title 找到原作品对象。
// 然后只修改需要更改的字段，不要复制出第二个重复作品。
{
  id: "early-dream-2026-05-24", // 一般不要改
  category: "writing",
  tags: ["诗", "梦"],
  zh: {
    title: "新的中文标题",
    summary: "新的中文摘要。",
    content: `这里写新的中文正文。
请保留诗歌和散文的原本换行。`,
    commentary: `这里写作品说明。`
  },
  ja: {
    title: "新的日文标题",
    summary: "新的日文摘要。",
    content: `ここに新しい日本語本文を書く。`,
    commentary: `ここに作品解説を書く。`
  }
}

常见修改场景

  1. 修改标题：改 zh.title 和 ja.title。
  2. 修改摘要：改 zh.summary 和 ja.summary。
  3. 修改正文：改 zh.content 和 ja.content，多行正文用反引号包住。
  4. 修改分类：改 category，但必须使用网站已有分类。
  5. 修改标签：改 tags，每个标签都要加引号，标签之间用逗号。
  6. 修改音乐文件：改 files 中 type: "audio" 的那一项，音频推荐放到 assets/audio/。
  7. 修改图片文件：改 images 数组，图片推荐放到 assets/images/works/ 对应分类文件夹。

修改已有作品时不要做的事

  • 不要把已有作品复制一份再改，否则会出现重复作品。
  • 不要随便修改 id，除非确定没有其他地方引用它。
  • 不要删除作品对象结尾的逗号。
  • 不要删除整个 works 数组的中括号。
  • 不要把多行正文写进普通双引号里。
  • 不要使用电脑完整路径；请使用从 assets/ 开始的相对路径。
  • 不要一次修改太多篇作品，最好一次改一篇，刷新确认没问题后再继续。

JS 格式安全提醒

        
如果你手动修改 data/works.js，多行正文最容易让作品列表消失。请特别注意下面几点：

        
    
          
  • 普通双引号 "..." 不能直接跨很多行；诗歌、散文等多行正文建议使用反引号 `...`。
    • 
          
  • 每个作品对象之间要有英文逗号 ,，不要漏掉对象之间的分隔。
    • 
          
  • 每个 {}、[]、" 和 ` 都要成对闭合。
    • 
          
  • 这个助手生成的代码会把换行处理成安全格式；如果再手动改正文，请尽量保留生成出来的外层字符串格式。
    • 
          
  • 如果作品突然全部不显示，优先检查最后一次修改的作品对象。
    •
